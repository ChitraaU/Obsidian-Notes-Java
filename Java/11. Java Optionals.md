**Null Pointer Exception**
The null Pointer exception is a runtime exception where it occurs when the user the tries to reference an object of null value.
Why the NullPointer Exception occurs :
1. Invoking a method having null value
2. Accessing or trying to modify the value of the object field that is null
3. Synchronizing a null object
4. Trying to modify an array having null value
5. modifiying or Accessing the slots of objects if it was array if they are null
6. Throwing null as if it was Throwable value
### Use case of Null

The null value serves as a placeholder and it indicates that no value is assigned to a reference variable. Common applications include:

- ****Linked Data Structures****: It represents the end of a list or tree branch.
- ****Design Patterns****: This is used in patterns like the Null Object Pattern or Singleton Pattern.

**Optional**

Optionals are part of the optional class and they are the containers which may or may not contain the null value ,they help in dealing with the Null Pointer Exception

- Used to handle null values safely.
- Reduces chances of NullPointerException.
- Provides methods to check and process values easily.
- Improves code readability
### Creating Optional Objects

- ****Optional.empty():**** Returns an empty Optional.
- ****Optional.of(value):**** Returns an Optional containing the given non-null value.
