
SQL Statements :
SQL statements are commands written in SQL to perform various operations on a database, such as reading, inserting, updating, and deleting data, as well as creating and modifying database objects. They are commonly referred to as SQL queries, although technically, a query usually refers to retrieving data from the database.


Types of statements:
**DDL -> Data Definition Language**
Used to define the structure of the database objects such as tables
**CREATE**,**ALTER**,**DROP**,**TRUNCATE** are the commands that come  under this 

**DML-> Data Manipulation language**
Used to insert ,delete or modify the data in the table
**INSERT, UPDATE, DELETE** are the commands that come under this.

**TCL -> Transaction Control language**
Used to **control transactions** in a database.
**Commit , Rollback and Savepoint** are the commands that come under this.

**DCL-> Data Control language**
Used to control access and permission to the database objects
**Grant and Revoke** are the commands that are used in this.

**DQL** → Data Query Language
Used to fetch the data from the table
**Select** is the command that comes under this

**Constraints**
These are the rules that are applied in a  table to maintain data integrity and consistency
***Common Constraints:***
****
PRIMARY KEY
FOREIGN KEY
NOT NULL
UNIQUE
CHECK
DEFAULT

**Primary Key**
A primary key is a column or a combination of columns that uniquely identifies each record in a column
A primary key:

- Must contain **unique values**
- Cannot contain **NULL**
- A table can have **only one primary key**
- The primary key can consist of **multiple columns** → called a composite primary key

**Foreign key**
A foreign key is a key that establishes the  relationship between two tables by referring to the primary key of another table

**Alter Table(ADD ,Modify, Drop)**
`ALTER TABLE` is a **DDL statement** used to modify the structure of an existing table.
Constraints
│
├── Primary Key → uniquely identifies a row
├── Foreign Key → establishes relationship between tables
├── NOT NULL → prevents NULL
├── UNIQUE → prevents duplicates
├── CHECK → validates a condition
└── DEFAULT → provides default value

ALTER TABLE
│
├── ADD → add column/constraint
├── MODIFY → modify column definition
└── DROP → remove column/constraint


**Joins**
A **JOIN** is used to combine data from **two or more tables** based on a related column.

**Inner Join**
An **INNER JOIN returns only the records that have a match in both tables.**

**Left Join /Left Outer Join**
A **LEFT JOIN returns all records from the left table**, plus matching records from the right table.

**Right Join/Right Outer Join**
A **RIGHT JOIN returns all records from the right table**, plus matching records from the left table.

# JOIN Summary

|JOIN|What it returns|
|---|---|
|**INNER JOIN**|Matching records from both|
|**LEFT JOIN**|All left + matching right|
|**RIGHT JOIN**|All right + matching left|
**Alias**
An **alias** is a temporary name given to a table or column to make SQL easier to read/write.
SELECT s.name, c.class_name
FROM students AS s
INNER JOIN classes AS c
ON s.class_id = c.class_id;


**Aggregations**
**Aggregate functions** perform calculations on multiple rows and return a single result per group (or one result for the whole result set).
COUNT()
SUM()
AVG()
MIN()
MAX()

### Important distinction

```
Aggregate function → calculates
GROUP BY → decides how rows are grouped
```
