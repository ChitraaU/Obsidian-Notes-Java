***Annotations***

***Annotations***

The annotations are special markers that are used to mark classes ,functions or field as different marks so that spring can use them as beans ,inject dependencies and perform operations.

@Component
`@Component` marks a class as a Spring-managed component. During component scanning, Spring discovers it and registers an object of that class as a bean.

@component("myBean")
if we have to give the bean a particular name then we write it like this.

Configuration class
This is the class from which we generally give the configuration details for the project and from where it can scan the package.
@Configuration
This tells that the particular  class is configuration class

@ComponentScan
Component Scan scans the classes that are marked as beans.
It **scans packages to find classes that are candidates for component registration**, such as:
@Component
@Service
@Repository
@Controller

@AutoWired
`@Autowired` is used on **constructors, fields, or methods** to tell Spring:
> **"Inject a suitable bean here."**
If a class has **one constructor**, Spring can automatically use that constructor for dependency injection, even without `@Autowired`.

- If a class has one constructor, Spring can automatically use that constructor for dependency injection without `@Autowired`.
- **Constructor injection is generally preferred over field injection** because dependencies become explicit and the object can be immutable/easier to test.

So remember:

Field injection       → possible

Setter/method injection → possible

Constructor injection → preferred

@Service
The service annotation is used to tell the spring this class would be the business class 

@Repository
The service annotation is used to tell the spring this class would be the  class  that uses the databases
Represents the **data-access/persistence layer**.

@Controller
The service annotation is used to tell the spring this class would be the  class  that uses  the endpoints with APIs
Handles web requests and belongs to the presentation/web layer.

@RestController
`@RestController` is used to create REST API endpoints and typically returns data directly in the HTTP response body as JSON
RestController/Controller interact with Service then it interact with Repository and the it goes the same way back
@Controller
     +
@ResponseBody
     =
@RestController
A `@RestController` is typically used for REST APIs where the return value is written directly to the HTTP response body, commonly as JSON.

@Qualifier(" ")
This specific annotation tells the Spring that it has to use the particular bean for injecting the dependency
@Primary
By default this bean would be used if we have marked a class as Primary
