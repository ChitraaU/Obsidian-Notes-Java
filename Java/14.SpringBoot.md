 ***SpringBoot : What it is and Why ?***

Spring Boot is a project built on top of the Spring Framework. It simplifies the development of Spring applications by providing auto-configuration, starter dependencies, embedded servers, and sensible defaults.
Spring Framework provides the features; Spring Boot makes it easier and faster to use those features.

***Spring Initializer***
Spring Initializr is a tool that generates the initial structure of a Spring Boot project based on the options and dependencies we select.
Spring Initializr is a platform/tool used to **create and initialize a Spring Boot project**.

It allows us to select things such as:

- Project type — Maven/Gradle
- Java
- Spring Boot version
- Dependencies

It then generates the basic project structure for us.

@EnableAutoConfiguration
`@EnableAutoConfiguration` tells Spring Boot to automatically configure the parts of application based on the dependencies present in the classpath and the application's configuration.
- Auto-configuration = Spring Boot automatically provides appropriate configuration based on what is present in the project.

WebServer Tomcat :- It is the embedded server that comes in the SpringBoot Project that helps in running the application.
It allows us to run our web application without separately installing and configuring an external Tomcat server.

For example:

```
Run Spring Boot Application
        ↓
Embedded Tomcat starts
        ↓
Application starts
        ↓
Server listens for HTTP requests
```

SpringBoot Starter Web : These are the dependencies that we can install that dependency into our project

Different Starter Web :
spring boot starter web
spring boot starter data jpa
spring boot starter security
spring boot starter test
Spring Boot Starters are **dependency bundles** that provide the libraries required for a particular functionality.

Common examples:
`spring-boot-starter-web`

Used for building web applications and REST APIs.
`spring-boot-starter-data-jpa`

Provides dependencies needed to work with JPA and database persistence.
`spring-boot-starter-security`

Provides dependencies for adding Spring Security.
`spring-boot-starter-test
Provides dependencies commonly used for testing Spring Boot applications.

**Important:** A starter isn't something that "installs a dependency into our project" by itself. Rather, **we add the starter as a dependency, and it brings a group of related dependencies with it.**

***Application Properties:-***
`application.properties` and `application.yml` are configuration files used to customize the behavior and settings of a Spring Boot application.

***Application Runner and Command LineRunner***

Both of these are the interfaces and we can use it to run the code at the time Application StartUp the difference is that in Application runner we can provide the arguments.

It can also contain things such as:

- Database configuration
- Server configuration
- Logging configuration
- Application-specific configuration

Spring Boot also supports:

```
application.yml
```
### CommandLineRunner

Allows us to execute code after the application has started and provides the command-line arguments as a **String array**.

### ApplicationRunner

Also executes code at application startup, but provides the command-line arguments in a more structured **ApplicationArguments** form.


***Servlet***

Servlet is a Java program that sits on the server and handles the HTTP request for Java web applicatins

Servlet = Java component that handles web requests on a serve

***Dispatcher Servlet***
DispatcherServlet is Spring MVC's central servlet. It receives the HTTP request that comes through the embedded Tomcat server and dispatches it to the appropriate controller/component.
Client / Browser
       ↓
HTTP Request
       ↓

Appropriate Controller
       ↓
Service
       ↓
Repository
       ↓
Database

DispatcherServlet is the front controller of Spring MVC. It receives incoming HTTP requests and dispatches them to the appropriate controller/handler for processing.

### `@SpringBootApplication`

> **`@SpringBootApplication` is the main annotation used on the main class of a Spring Boot application.**

It effectively combines three annotations:

```
@SpringBootConfiguration
@EnableAutoConfiguration
@ComponentScan
```

What are startup dependencies and what does "Opioniated Setup" means ? 
The startup dependenices are baiscally the the bundles of dependencies that are provided to the springboot project  which include alot of different libraries that might be required in the project.
SpringBoot provides us with some default configurations at the start of projects when we select the dependencies that we want to use that means it is an Opiniated Setup.

What is Springboot Auto Configuration and how does it work ?
It allows to configure the dependencies that are already present in the classpath and the application configuration, for example if we have startup web dependency so now the dependency is already present now the Springboot detects it and applies the appropriate web configurations
