***Entity Manager***

So entity Manager is basically a contract or we can say a specification of JPA which the hibernate implements in the hindesite we can say that the implementation the raw level is hibernate but EntityManager provides an abstraction between your application code and the JPA implementation (such as Hibernate).

**JPA = rules/contract**  
**EntityManager = JPA's main API for managing entities**  
**Hibernate = implementation of those rules**  
**JDBC = lower-level database communication used by Hibernate**  
**Database = where the data ultimately lives
**

Your Application
       ↓
   EntityManager
       ↓
      JPA
 (Specification)
       ↓
 Hibernate
 (Implementation)
       ↓
   JDBC
       ↓
   Database


#### Different Implementors of JPA

The major JPA implementations/providers are:

|JPA Implementation|Organization|Notes|
|---|---|---|
|**Hibernate ORM**|Red Hat / Hibernate community|Most commonly used JPA provider; widely used with Spring Boot|
|**EclipseLink**|Eclipse Foundation|Reference implementation lineage for Jakarta Persistence; widely used|
|**OpenJPA**|Apache Software Foundation|Apache's JPA implementation|
|**DataNucleus**|DataNucleus|Supports JPA along with other persistence APIs|

#### Wrapper Methods
By **“wrapper methods”** you mean _which methods are the higher-level methods that hide the lower-level JPA/Hibernate operations_, then in **Spring Data JPA**, these are mainly the methods provided by `JpaRepository` / `CrudRepository`.

For example:

|Spring Data JPA method|What it abstracts underneath|
|---|---|
|`save()`|`EntityManager.persist()` or `merge()`|
|`findById()`|`EntityManager.find()`|
|`findAll()`|JPA query / `EntityManager` operations|
|`delete()`|`EntityManager.remove()`|
|`deleteById()`|Find entity + remove it|
|`existsById()`|JPA query to check existence|
|`count()`|JPA/JPQL count operation|

`save()`, `findAll()`, `findById()`, `delete()` etc. are Spring Data JPA repository methods that abstract the lower-level JPA `EntityManager` operations, which are then implemented by Hibernate.
Spring data JPA also used the Entity manager behind the scenes.

So:

JPA
 └── EntityManager          ← standard JPA API

Spring Data JPA
 └── JpaRepository
       ├── save()
       ├── findAll()
       ├── findById()
       ├── delete()
       └── ...
